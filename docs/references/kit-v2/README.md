# Kit v2 references (24 November 2026)

These are the approved visual references for the canyon kit v2 and arena-02. See [artdirection.md](../../artdirection.md) for the rules.

- `01`–`04`: modelling sheets, each showing front, right, back, top and ¾ views with dimensions. Front is −Y, right is +X, and Blender is Z-up.
- `05-all-in-one-kit.jpg`: a single sheet with the extra pieces. These are the ground block, small shrub, 2 m fence, bone pile and rock tiles.
- `concept-gameplay-primary.jpg`: the target composition and look through the gameplay camera.
- `concept-gameplay-haki-*.jpg`: Haki caches, orbs and effects in play.

The turnarounds are generated drawings, not measured projections. When a drawing and a written dimension disagree, follow the written dimension.
