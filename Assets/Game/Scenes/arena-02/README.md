# Arena 02

The visual target is [docs/artdirection.md](../../../../docs/artdirection.md), with colours in [docs/palette.json](../../../../docs/palette.json). This README describes the scene and its workflow; it is not a visual approval.

`arena-02.blend` is the editable arena. It is rebuilt by the recipe `tools/blender/arenas/arena_02.py`; change the recipe and rebuild instead of hand-editing instances.

The scene JSON, `Catalog.json`, materials, textures and `Models/arena.glb` are generated by the Haki add-on's **Export Arena**. `Source/ground_color.png` is the baked ground colour map the recipe paints.

## Rebuild and export
Open `arena-02.blend`, then in Blender (for example through Blender MCP):

```python
import runpy; ns = runpy.run_path("tools/blender/arenas/arena_02.py")
ns["build"]()          # rebuild collections, camera, sun and colliders, then validate
ns["render_checks"]()  # optional gameplay-camera renders into build/arena-02-previews/
ns["export"]()         # Export Arena with import, then apply the map's environment intensity
```

Use `export()` rather than the sidebar button for now. The add-on always writes environment intensity 1.0, which bleaches the arena. `export()` resets it to the tuned `ENVIRONMENT_INTENSITY` (0.4).

## Layout
- **Playable area:** 24×24 m, with 4-fold rotational symmetry so every side gets the same cover. The build fails if the layout disconnects the walkable cells.
  - L-shaped cover pockets, wall stubs and low walls, built from the continuous `wall_*` modules.
  - Joined `grass_*` concealment patches, each a nonblocking 1×1×0.9 m trigger per cell.
  - Static crates and a centre pond.
- **Boundary:** each side has a visible reason movement stops; simple hidden box colliders sit at the playable edge.
  - **North:** a rocky rise.
  - **East:** a dry bank with grouped brush and cacti.
  - **West:** a stream with a fence section.
  - **South (foreground):** low ledges and low shrubs, at most 0.5 m, so nothing hides the player.
- **Outskirts:** continued terrain with mounds and worn paths, plus grouped boulders, shrubs and cacti.
- **`Player`:** a mesh-free character controller running `Scripts/player.lua`.

## Camera and coverage
- **Benchmark camera:** perspective, 57° pitch, 25° vertical FOV, 25.4 m from the focus. This is the art direction's section 1 profile.
- **Terrain size:** the terrain rectangle (`coverage()` in the recipe: x −32…32, Blender y −22…24) covers every camera footprint for any focus in the playable square, at 16:9, 16:10 and 21:9, plus 4 m.
- **Camera follow:** `Scripts/arena_rules.lua` keeps the startup framing until the player nears a screen edge, then pans. It clamps the focus so the whole frustum footprint stays inside that same rectangle, given as `coverage_*` properties in engine X/Z.
- **Keep in sync:** if you change the camera or the terrain, update both the recipe and the script.

## Lighting
- **Sun:** one afternoon sun, 52° elevation from the south-west, intensity 2.4, warm colour.
- **Environment:** the engine default environment at 0.4.
- **Render values:** exposure, ambient, bloom, shadow and SSAO values live in `Assets/Game/Project.json` → `rendering`. They were tuned together with the sun and environment.
